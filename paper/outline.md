# Paper Outline

## Working Title

ARFA: Residual-Guided Reasoning Control for Terminal-Based Coding Agents

## Core Question

After a terminal-based coding agent executes a command and receives an observation, does it always need another expensive reasoning call?

## Hypothesis

The discrepancy between a pre-execution expected outcome and the actual terminal observation can provide a useful signal for deciding whether renewed reasoning is necessary.
