# Limitations

- InterCode trajectories contain actions and observations, but not pre-execution expectations. Expectations are currently generated as an ARFA annotation layer.
- Labels are currently heuristic/self-pass annotations and need human review.
- Current semantic residual may use TF-IDF fallback if the embedding model is unavailable.
- InterCode Bash is terminal-oriented but not equivalent to full software-engineering bug fixing.
- Phase 2 and Phase 3 claims should not be made until the Phase 1 evidence gate is reviewed.
