# Project Overview

## Title

ARFA: Residual-Guided Reasoning Control for Terminal-Based Coding Agents

## Core Claim

For terminal-based coding agents, the most relevant uncertainty after an execution step is whether the observed output matches the expected outcome. If it matches, the existing plan may continue. If it deviates, the agent should reason again.

## Phase Deliverables

Phase 1 delivers a labeled terminal-step dataset, residual scores, metrics, plots, false-fast analysis, and a report.

Phase 2 delivers a reproducible ReAct baseline that always reasons after every observation.

Phase 3 delivers the ARFA router, fast track, slow track, and comparison against the ReAct baseline.
