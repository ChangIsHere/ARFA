# Experiment Protocol

## Phase Gate

Phase 1 must produce:

- at least 50 labeled terminal steps
- embedding, rule-based, and hybrid residual scores
- reproducible metrics
- false-fast cases
- written report

Only after review should Phase 2 begin.

## Reproducibility

Each phase must be runnable from a shell script in `scripts/`.

Generated outputs belong in `results/`.

Raw, generated, and labeled data belong in `data/`.
