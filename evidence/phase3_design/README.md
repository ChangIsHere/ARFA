# Phase 3 Design Record

`preflight.json` records the inputs checked before Phase 3 formal runs: task
coverage, historical 14B and 7B outcomes, and hashes of the config, split,
dataset, and baseline files. It contains no Phase 3 outcomes.

Run `bash scripts/phase3_study_preflight.sh` from the repository root to refresh
it from local Phase 2 outputs. The intended decision rules and the reason for the
five-point margin are in `docs/phase3_study_protocol.md`.
